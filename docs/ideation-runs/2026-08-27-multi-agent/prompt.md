# Independent WebMCP Challenge ideation brief

You are one of several independent ideation agents. Work from first principles and return your own original thinking. You have not been shown any concepts from the organizer, the requesting team, or other agents.

Do not inspect the filesystem, repository, conversation history, or other agent outputs. Do not browse or search the web. Do not write or edit files. Produce only your final Markdown response on stdout.

## What WebMCP is

WebMCP is an emerging open standard that lets websites expose structured tools directly to AI agents. A web app can register tools with names, descriptions, input schemas, and execution behavior. This gives an agent a reliable application-specific action surface instead of forcing it to infer every action from pixels or DOM interactions. The human still uses the normal visual product, while the agent can use the structured tools exposed by that same product.

## The challenge

The WebMCP Challenge is an online Devpost hackathon sponsored by OpenAI and administered by Devpost. Its official build goal is:

> Build a WebMCP-powered web app that imagines and explores the future of the open web—where humans and agents can interact, collaborate, and create together.

The organizer wants applications that become meaningfully better when people and their agents use them together. WebMCP should be essential to the product experience, not a decorative integration.

## Judging

Stage one is a pass/fail viability screen: the project must fit the theme and genuinely use WebMCP.

Stage two scores four equally weighted criteria on a five-point scale:

1. **WebMCP Leverage** — thorough, skilful, working, non-trivial WebMCP use backed by genuine implementation effort.
2. **Execution** — a complete, coherent, runnable product experience rather than only a technical proof of concept.
3. **Potential Impact** — a credible, specific real problem and audience, with a demonstrated solution that actually addresses it.
4. **Creativity & Ambition** — a novel concept meaningfully different from existing ideas.

WebMCP Leverage is the first tie-break criterion.

## Delivery constraints

- The team has about one week to produce a convincing proof of concept.
- The submission needs a working live URL usable from ChatGPT's in-app browser or WebMCP-enabled Chrome.
- It needs a public, openly licensed source repository with the WebMCP implementation visible.
- It needs a public YouTube demonstration under three minutes with audio.
- A new project is preferred. A pre-existing project would be judged only on meaningful WebMCP extensions built during the challenge.
- Judges may interact with the live product but may also judge entirely from the description, repository, and video, so the central value must be legible quickly.

## Your assignment

Generate **10 genuinely distinct product ideas** for this challenge. Seek ideas that reveal new interaction patterns made possible by a website exposing structured tools to an agent while a human remains an active participant. Avoid producing ten variations of one pattern.

For every idea provide:

- a memorable working title;
- the specific user and painful problem;
- the core human experience;
- the agent's role;
- 3–6 concrete WebMCP tools the site would expose;
- why WebMCP is essential rather than replaceable by an ordinary chatbot or generic browser automation;
- the under-three-minute demo moment;
- a one-week proof-of-concept scope;
- the largest product or technical risk;
- a 1–5 score for each official judging criterion.

Then:

1. Select your strongest three ideas.
2. Explain the non-obvious insight behind each selection.
3. Name the single idea you would build to win and give it a concise strategic rationale.
4. Include one deliberately ambitious wildcard that may be difficult but could redefine expectations for WebMCP.

Do not ask questions. Make reasonable assumptions and complete the ideation independently.
