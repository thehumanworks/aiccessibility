# The WebMCP Challenge documentation

This directory is the local, agent-readable reference for [The WebMCP Challenge](https://webmcp.devpost.com/), an online Devpost hackathon hosted by OpenAI.

The challenge runs for ten days and asks entrants to build a WebMCP-powered web app that explores the future of the open web: people and agents interacting, collaborating, and creating together. The central product test is not merely “does it expose a tool?” but “does the app become meaningfully better when a person and an agent can use it together?”
